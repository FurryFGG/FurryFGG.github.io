# FurryFGG 风光狗的个人网站

这是一个无需构建工具的静态网站，可直接部署到 GitHub Pages。

## 本地预览

直接打开 `index.html` 可以查看基础页面。为了完整测试站内链接和浏览器功能，也可以在项目目录启动任意静态文件服务器。

## 更新摄影作品

原始照片保存在 `相册/风光/`、`相册/furry/` 的对应活动目录和 `相册/飞机/` 中。`相册/风光/` 内文件名以 `DJI` 开头的照片会自动归入“航拍”，其余照片归入“风光”；`相册/飞机/` 中的照片单独归入“飞机”。更新原片后，在项目目录运行：

```powershell
& .\tools\build-gallery.ps1
```

脚本会按 EXIF 拍摄时间从新到旧整理照片，并自动生成压缩后的 JPEG 网页副本、首页封面、签名背景以及 `gallery-data.js`，无需逐张编辑 HTML。网页作品长边为 1600 像素并启用延迟加载；原始照片不会被修改。照片没有 EXIF 拍摄时间时，脚本会使用文件修改时间作为排序回退值，但网页不会显示这个回退时间。

作品页的顶级分类顺序固定为“风光、福瑞 Furry、飞机”。页面使用保持原始比例的等高拼接行：脚本会按屏幕宽度为相邻照片选择合适的行组合，横图、竖图和全景图都不会裁切或拉伸，也不会产生瀑布流式的中间空洞；最后一行保持自然尺寸。原相册目录滚出视野后，页面右侧会显示快速目录和“返回标签页最上方”按钮，手机端为整个控件预留独立空间；该按钮直接返回整个网页顶部。从其他页面进入、刷新或通过浏览器历史记录返回时，网站也会回到当前网页最上方，不恢复旧滚动位置；点击作品页的顶级分类时回到作品标签栏顶部，页内相册目录仍可跳转到指定作品位置。全屏照片使用带方向感的淡出、滑动和柔和淡入动画切换。

## 发布

仓库目标：<https://github.com/FurryFGG/FurryFGG.github.io>

站点域名由根目录的 `CNAME` 文件指定为 `furryfgg.com`。发布后还需要在域名服务商处配置 GitHub Pages 所需 DNS 记录，并在仓库 Pages 设置中启用 HTTPS。
